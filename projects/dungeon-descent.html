Dungeon Descent

A playable game-development study built in C, using Win32 APIs and GDI without a conventional game engine.

01 / Context

Gameplay from the ground up.

Dungeon Descent is an early Windows dungeon-crawler prototype written in C, using native Win32 APIs and GDI rather than a dedicated game engine.

The project explores input handling, character classes, rendering, menus, combat, abilities and progression. Some systems are incomplete, and others still need work.

The Knight's attributes were raised for a demonstration, so they do not reflect the intended game balance.
