Wildgrade

An experimental browser driving world with procedurally assembled environments and arcade-style vehicle behavior.

Project type
Browser driving prototype
Tools
JavaScript · WebGL / Canvas 2D
Visual focus
Low-poly environments
Status
Documented earlier build
01 / Context

A world built for exploration.

Wildgrade is a browser-based driving experiment that combines low-poly landscapes, dynamic terrain sectors, winding roads, and an arcade driving system. The captures on this page come from an earlier version of the project.

It is a work in progress, not a released driving game. Driving is intentionally arcade-like, automatic navigation is experimental, and performance depends on the browser and hardware.

The public GitHub repository contains the screenshots, film and project notes. It does not include a playable build, source code or 3D models.

03 / Systems

Behind the scenes.

01 / Movement

Acceleration, braking, steering and handbrake form the driving interaction, with simplified physics and terrain contact.

02 / World generation

Roads, vegetation, terrain variation and water are assembled from terrain sectors to support extended exploration.

03 / Visual output

Browser rendering using WebGL, with a Canvas 2D fallback. The captured portfolio footage is from a running prototype.

04 / Automatic driving

Experimental autonomous navigation; not a complete or production-grade AI driving system.

05 / Interface

Controls for driving, visual quality, cameras and sound, developed iteratively alongside the simulation.

06 / Current status

This is an earlier version of an ongoing experiment, not a finished release.
